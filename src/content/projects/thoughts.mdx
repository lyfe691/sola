# A notebook, not a portfolio

Thoughts is where I write the things that do not fit a project page: reflections, fragments and notes. It sits apart from this portfolio on purpose. A portfolio shows finished work, and a notebook is allowed to be unfinished.

## Text first

The design is a single column, careful type and a lot of white space, and the navigation is three words.

Even the dead ends are written. The 404 page is a short verse, and one of its lines sets the tone: “You were never supposed to be here.”

## A post is a file

The site is a Next.js app, and every post is an MDX file with a little metadata: a title, a date and a description. Publishing means adding a file to one folder. The page that renders a post imports it by its slug:

<CodeBlock
  code={`// thoughts/[slug]/page.tsx
  const { default: MDXContent, metadata } = await import(
    '../_articles/' + \`\${params.slug}.mdx\`
  )
  return (
    <div lang={metadata.chinese ? "zh-Hans" : "en"}>
      <MDXContent />
    </div>
  )`}
  fileName="page.tsx"
  lang="typescript"
/>

The `lang` attribute follows the post, so a note written in Chinese is announced as Chinese to browsers and screen readers.

## The guestbook

Personal sites used to have guestbooks, and I wanted one. Visitors leave a name, which is optional, and a message of up to 280 characters. Entries are stored in Postgres on Vercel.

## Where the idea came from

The site is directly inspired by [Shu Ding](https://shud.in)’s personal website: simple, text-first and quietly expressive. I wanted a place like that for myself, less polished than a portfolio and more open-ended.
