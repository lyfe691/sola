# Every job application in one place

AppliCare is a web app for keeping track of job applications. It came out of my own job search: I was losing track of where I had applied, what stage each application was at, and which follow-ups I still owed.

## What you can do with it

- **Applications.** Each one carries its status, from applied to offer, along with a contact and your notes. A Manage page filters and sorts them.
- **Tasks.** A task has a deadline and a priority and can be linked to an application, so “send a thank-you note” stays attached to the interview it belongs to.
- **Dashboard.** Totals, a success rate, a graph of applications over time, and the tasks that are due.

## How it is built

The frontend is React with Vite, using [Ant Design](https://ant.design) for its components. The backend is a Spring Boot service that stores its data in MongoDB. Signing in returns a JSON Web Token, a signed pass the browser sends along with every request, and a filter on the server checks it before any controller runs.

The backend ships as a Docker image built in two stages: one that compiles the app, and a smaller one that only runs it.

  COPY --from=build \${DEPENDENCY}/BOOT-INF/classes /app
  ENTRYPOINT ["java","-cp","app:app/lib/*","com.applicare.applicare.ApplicareApplication"]`}
  fileName="Dockerfile"

## Where it came from

I built AppliCare between December 2024 and February 2025 for two school modules, one on frontends and one on backends, which is why it is a complete app with both halves written from scratch.
