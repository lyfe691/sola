# A dog's website that doubles as a template

Taco is my brother's Pomeranian, and this is his website. I built it as something I could reuse: a small multi-page site with translations, colour themes and a blog already wired up, so the next site of this kind starts from a working base.

## Languages, detected on arrival

The site speaks English, Spanish and Japanese. On a first visit it reads the browser's language and uses it if the site has it; otherwise it falls back to English:

<CodeBlock
  code={`export function detectUserLanguage(): string {
    if (typeof window !== 'undefined' && typeof navigator !== 'undefined') {
      const browserLang = navigator.language || navigator.languages[0];
      const langCode = browserLang.split('-')[0];
      return languages.some(lang => lang.code === langCode)
        ? langCode
        : fallbackLanguageCode;
    }
    return fallbackLanguageCode;
  }`}
  fileName="lib/i18n/index.ts"
  lang="ts"
/>

A choice made in the language menu is saved in `localStorage` and wins over detection on the next visit. The strings live in one JSON file per language, and a provider hands every page the current language and a `t` function, so adding a language is one more file and one more entry in the list.

## Named themes instead of light and dark

The site does not follow the system's light or dark setting. The visitor picks a named theme from a menu: Green is the default, and Night is the dark one.
