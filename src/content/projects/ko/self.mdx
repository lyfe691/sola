# Windows PowerShell용 Neofetch 스타일 시스템 정보

Self는 Linux의 [Neofetch](https://github.com/dylanaraps/neofetch)처럼 Windows PowerShell에서 이미지 하나와 시스템 정보 한 열을 나란히 출력합니다. 이미지는 어떤 이미지 파일이든 될 수 있고 색을 입힌 텍스트 문자로 터미널에 다시 그려지며, 정보는 Windows 에디션부터 디스크까지 이어집니다.

## 출력되는 내용

왼쪽에는 `images` 폴더의 이미지, 또는 `--image`로 넘긴 임의의 파일이 문자 단위로 지정한 높이와 너비에 맞춰 축소되어 나타납니다. 문자 칸 하나에 픽셀이 두 개 들어가고 모든 픽셀이 24비트 이스케이프 코드로 자기만의 색을 유지하기 때문에, 사진이나 그림은 가로 수십 글자 정도에서도 알아볼 수 있습니다. 점자 모드는 그 대신 더 고운 점으로 그리며, 칸마다 색은 하나입니다.

오른쪽에는 `user@host` 아래로 Windows 에디션, 가동 시간, Chocolatey, Scoop, winget의 패키지 수, 셸, 화면 해상도와 테마, 프로세서, 그래픽 카드, 메모리, 디스크가 차례로 나옵니다. 어떤 줄을 표시할지는 설정이 정하고, 라벨의 색은 컬러 테마가 정합니다. 이 열은 정보를 모으는 데 걸린 시간과 고전적인 콘솔 색 열여섯 가지가 한 줄로 늘어선 것으로 끝납니다.

## ASCII 아트

`--ascii`는 이미지 대신 `ascii` 폴더의 그림을 표시합니다. 이 그림은 일반 텍스트 파일이고, Self는 적힌 그대로 출력합니다. 문자로 이루어진 것이라면 무엇이든 되고, 여기 보이는 것처럼 점자 점으로 만든 그림도 됩니다.

## 설치와 설정

Self는 PowerShell 한 줄로 설치됩니다.

```powershell
iwr -Uri "https://raw.githubusercontent.com/lyfe691/self/main/install.ps1" -UseBasicParsing | iex
```

이 스크립트는 Self를 사용자 프로필의 `self` 폴더에 내려받고, `self.bat` 런처를 추가하고, 그 폴더를 사용자의 `PATH`에 넣고, pip으로 Python 패키지를 설치합니다. Python은 필요하지만 관리자 권한은 필요하지 않습니다. 그 뒤로 `self`는 다른 명령어와 다를 바 없는 하나의 명령어가 됩니다.

| 명령                  | 동작                                                                          |
| --------------------- | ----------------------------------------------------------------------------- |
| `self`                | 이미지와 정보를 출력합니다                                                    |
| `self --setup`        | 표시 방식, 이미지 또는 그림, 테마, 크기를 물어보고 `config.json`에 저장합니다 |
| `self --image <file>` | `images` 폴더나 임의의 경로에 있는 다른 이미지를 사용합니다                   |
| `self --ascii <name>` | 이미지 대신 `ascii` 폴더의 그림을 사용합니다                                  |
| `self --no-cache`     | 5분 캐시를 쓰지 않고 정보를 새로 수집합니다                                   |
| `self --update`       | 최신 버전을 받아 오되 설정, 캐시, 직접 추가한 이미지는 그대로 둡니다          |

## 구현 방식

Self는 표시, 이미지, 정보, 컬러 테마의 네 모듈로 이루어진 작은 Python 프로그램입니다. Pillow가 이미지를 읽고 크기를 조정하고, psutil이 메모리와 디스크, 가동 시간을 알려 주며, colorama가 테마 색을 제공합니다.

### 문자 하나에 픽셀 두 개

터미널의 문자 칸은 높이가 너비의 약 두 배입니다. 반 블록 문자 `▀`는 칸의 위쪽 절반을 전경색으로 채우고 아래쪽 절반은 배경색에 맡기므로, 둘 다 지정한 칸에는 거의 정사각형인 픽셀 두 개가 들어갑니다. `rgb_to_ansi`가 이스케이프 코드 두 개를 만드는데, 전경색용은 `\033[38;2;r;g;bm`, 배경색용은 `\033[48;2;r;g;bm`이고, 블록 모드는 이미지를 한 번에 두 행씩 훑습니다.

<CodeBlock
  code={`for y in range(0, img_height, 2):
      line = ""
      for x in range(img_width):
          r_upper, g_upper, b_upper = pixels[x, y]
          if y + 1 < img_height:
              r_lower, g_lower, b_lower = pixels[x, y + 1]
          else:
              r_lower, g_lower, b_lower = r_upper, g_upper, b_upper
          # '▀' character (upper half block)
          line += f"{rgb_to_ansi(r_upper, g_upper, b_upper)}{rgb_to_ansi(r_lower, g_lower, b_lower, bg=True)}▀{RESET}"
      lines.append(line)`}

높이와 너비가 같으면 블록 모드는 너비를 두 배로 늘립니다. 정사각형 이미지에는 행 수의 두 배만큼 열이 필요하기 때문입니다. 맨 위 영상의 26 × 26 설정은 52 × 52 픽셀 이미지가 되고, Pillow가 최근접 이웃 샘플링으로 크기를 조정해 52자짜리 행 26개로 출력합니다.

### 보이는 너비를 기준으로 채우기

이 행들은 깁니다. 칸마다 전경색 코드, 배경색 코드, 문자, 리셋 코드가 붙기 때문에, 그 이미지의 한 행은 보이는 열이 52개인데도 약 1,900자에 이르고, `len()`은 이를 모두 셉니다. 정보 열을 이미지 옆에 가지런히 맞추기 위해 Self는 정규 표현식으로 이스케이프 코드를 걷어 낸 뒤 각 행의 길이를 재고, 짧은 행은 가장 넓은 행에 맞춰 공백으로 채웁니다.

### 점자 문자 하나에 점 여덟 개

점자 모드는 색을 내주고 해상도를 얻습니다. 유니코드의 점자 블록은 U+2800에서 시작하며 칸의 점 여덟 개를 오프셋의 비트로 인코딩하므로, 2 × 4 격자 위의 어떤 패턴이든 문자 하나가 됩니다. 번호 체계는 역사적인 것으로, 1~3번 점은 왼쪽 열을 따라 내려가고 4~6번 점은 오른쪽 열을 따라 내려가며, 7번과 8번 점은 나중에 8점 점자를 위해 추가되었기 때문에 맨 아래 행은 6번과 7번 비트입니다. 픽셀 위치에서 비트로의 대응은 다음과 같습니다.

어두운 터미널에서는 점자 점이 이미지의 어두운 부분을 따라 그려지고 색이 대부분 사라지기 때문에, README는 블록 모드를 권장합니다.

### 정보를 위한 5분 캐시

psutil 라이브러리는 가동 시간, 메모리, 디스크를 직접 알려 줍니다. 나머지 대부분의 줄은 짧은 PowerShell 명령에서 나옵니다. Windows 에디션, 레지스트리에서 읽는 테마, 패키지 수가 그렇습니다. 조회마다 제한 시간 2초의 `powershell.exe`를 따로 띄우므로 느린 응답 하나가 나머지를 붙잡을 수 없고, `-NoProfile`을 붙이므로 사용자의 프로필 스크립트가 매번 실행되지 않습니다. 더 느린 조회 열 개는 스레드 풀에서 병렬로 실행됩니다.

결과는 `cache/sysinfo.json`에 5분 동안 보관되고, `--no-cache`를 쓰면 건너뜁니다. “Executed in” 줄은 이 단계의 시간을 잽니다. 제 컴퓨터에서 새로 실행하면 약 1초가 걸리고, 캐시된 결과는 0.00초가 걸립니다. 렌더링된 이미지도 하루 동안 캐시되며, 파일 경로와 수정 시각, 크기, 모드를 키로 씁니다.
