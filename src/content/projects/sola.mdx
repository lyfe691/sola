# The site you are on

Sola is this website. It shows my projects, my experience and how to reach me, in six languages, eleven themes and seven animated backgrounds. This page is about how it is built.

## Make it yours

The menu in the corner changes how the whole site looks. There are eleven themes, from plain light and dark to ones with a character of their own like Cyberpunk, Forest and Coffee, and seven backgrounds that move behind the content, among them Aurora, Silk Waves and Liquid Ether. A first visit follows your system's light or dark setting, and whatever you pick is remembered.

Every theme is a set of colour tokens, and components only ever name a token, never a colour. That is why a new theme is one block of CSS and nothing in the components has to change. The backgrounds are drawn with WebGL and load only when they are chosen, so a visitor never downloads one they do not look at.

## Six languages without a library

The site runs in English, German, Spanish, Japanese, Korean and Chinese. The translations are plain TypeScript objects. The English file defines the type, and every other language has to match it, so a missing sentence is a build error instead of a blank spot on the page. No string a visitor reads is written inside a component.

## One list of pages

Every page is one entry in a single file. The router, the layout and the title in the browser tab all read from it, so adding a page means adding an entry:

<CodeBlock
  code={`export interface AppRoute {
    path: string;
    Component: LazyExoticComponent<ComponentType>;
    layout: RouteLayout;
    /** tab title, resolved against the active locale */
    title: (t: Translation, params: RouteParams) => string;
  }
  export const APP_ROUTES: AppRoute[] = [
    {
      path: "/projects",
      layout: "app",
      Component: lazy(() => import("@/pages/Projects")),
      title: (t) => t.projects.title,
    },
    // twelve more
  ];`}
  fileName="src/config/routes.ts"
  lang="ts"
/>

A route cannot exist without a title, and the title is the same string the page shows as its heading, so the tab and the page can never disagree. Each page is loaded only when it is opened.

## The project pages

The project cards come from one config file, and the longer write-ups, like this one, are MDX files. Each project has a painted cover: on a card it is a small SVG, a band of light across a dark field in the project's two colours, drawn in one of six shapes so that no two neighbours look alike. On a project's own page the same colours become a slow watercolour, painted live.

On a desktop, a rail of thin lines on the left edge of a project page marks its sections. It appears once you scroll into the article, the line for the section you are reading is longer, and pointing at a line shows the section's name.

## Motion

All movement on the site uses one small set of curves, defined once and shared by the CSS and the animation code. Buttons and menus move briefly. Content glides in more slowly as you reach it. Scrolling is smoothed with Lenis, and it pauses correctly while a menu or a dialog is open. If your system asks for reduced motion, the interface stops moving.

## How it ships

The site is a React 19 and TypeScript app built with Vite and styled with Tailwind CSS, hosted on Vercel. Every commit runs the linter, a format check, the type checker, the tests and a production build before it goes live. The [changelog](/changelog) page reads the site's own git history, so you can open any commit and see what changed. The source is [on GitHub](https://github.com/lyfe691/sola).
