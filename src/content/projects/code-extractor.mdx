# One click, one ZIP

Website Code Extractor is a browser extension for Chrome and Edge. Open any website, click the extension, and it downloads the page's HTML, CSS, JavaScript and images as a single ZIP file, with the folders kept in order. It started as a tool for myself, and 6,000 people now use it.

## Why I built it

I often wanted to see how a site did something: a layout, an animation, a small trick. The browser's “View Source” shows one file at a time, and saving pages by hand is slow and loses the structure. I wanted the whole page on my disk, arranged the way the site arranges it, in one step.

## How it works

The popup has one button. Pressing it runs a small script inside the open tab that reads the page's HTML, including its doctype, and hands it back to the extension. The extension then collects every stylesheet, script and image the page links to, downloads them, and puts everything into a ZIP named after the site.

The part that makes the download usable is the rewriting of links. A page refers to its files in many ways: full addresses, paths from the site's root, paths relative to the page. The extension turns each one into a full address to download from, then into a folder path inside the ZIP, and writes that path back into the HTML, so the saved page still finds its own files:

<CodeBlock
  code={`// simplified from popup.js
  const elements = doc.querySelectorAll('link[href], script[src], img[src]');
  elements.forEach(element => {
    const attr = element.tagName === 'LINK' ? 'href' : 'src';
    let url = element.getAttribute(attr);
    if (url) {
      if (!url.startsWith('http')) {
        url = new URL(url, baseUrl).href;
      }
      const urlObject = new URL(url);
      const path = urlObject.hostname + urlObject.pathname;
      resources.push({ url, path });
      element.setAttribute(attr, path);
    }
  });`}
  fileName="popup.js"
  lang="js"
/>

## What it is made of

Plain JavaScript on Manifest V3, the current format for Chrome extensions, with [JSZip](https://stuk.github.io/jszip/) to build the archive. Everything happens inside your browser, so the pages you save stay on your machine. It asks only for the permissions it uses: the active tab, scripting and downloads.

## Who it is for

It works best on static sites, where the page you see is made of the files the server sends. A site built as an app, with React or Next.js, assembles itself in the browser, so its downloaded files tell you less. One review on the store puts it well: “this tool works really great for small websites! the zip packaging works and even keeps the website structure intact.”
