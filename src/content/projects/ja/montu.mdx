# Montu、スイスの山行記録

[montu.ch](https://montu.ch) は、友人がスイスで歩いた夏と冬の山行をまとめたサイトで、どの山行にも彼自身の写真が付き、ドイツ語で書かれています。サイトは私が彼のために作り、新しい山行は、ブラウザ上のコンテンツエディタから、彼が自分で公開しています。

## 彼が望んだこと

彼が求めたのは、山行を、自分が覚えているとおりに残しておける場所でした。サイトは自分の言葉でこう語っています。技術的な情報はあくまで「sanfte Wegweiser」（穏やかな道しるべ）にすぎず、全体は「mehr Tagebuch als Führer」、つまりガイドブックというより日記だ、と。そのため、どのページも写真と彼の文章で始まり、数値は、行ってみたい人のために、そのあとに続きます。

## 山行のページ

山行のページは、上から下へ次の順に読めます。

1. タイトルの写真。山行の種類、グレード、地域、標高の範囲、日付が添えられます。
2. 彼による導入文。
3. 主要データ、標高プロファイル、地図。
4. ステージが順に続きます。
5. ルート沿いの山小屋、リフト、その他の場所へのリンク。彼が追加した山行にだけ付きます。

## ステージ

各ステージには、めくりながら見られる専用の写真があり、写真にはそれぞれキャプションが付き、その隣にステージごとの数値と文章が並びます。ルートの一部を、たとえばケーブルカーに乗って省略できる場合、そのステージの最後に、代替案がオレンジ色の注記で添えられます。

## 1 つの GPS ファイルから作る地図と標高プロファイル

GPS ウォッチやスマートフォンのアプリは、山行を GPX ファイルとして記録します。ルートを、高度付きの点のリストとして持つファイルです。彼はその 1 つのファイルを山行にアップロードします。ページはルートを地形図の上に描き、スタートに緑、ゴールにオレンジのピンを立て、同じ点から標高プロファイルをプロットします。プロファイルは自分でスケールを決めるので、短い山スキーも長い縦走も見やすく表示され、プロファイルに沿ってポインターを動かすと、標高が読み出されます。

グレードはスイス・アルパイン・クラブの尺度に従っています。

| 山行                 | 尺度                                                          |
| -------------------- | ------------------------------------------------------------- |
| ハイキング           | T1（楽な歩き）から T6（難易度の高いアルパインハイキング）まで |
| 山スキーとアルパイン | L（易しい）から EX（極めて難しい）まで                        |
| スノーシュー         | WT1（楽な歩き）から WT6（負荷の大きいアルパインツアー）まで   |

山行のグレードにポインターを重ねるかタップすると、その意味が言葉で説明され、尺度の名前が示され、尺度の解説へのリンクが表示されます。

## 彼が自分で編集するもの

サイトは Next.js で作られていて、訪れた人が読むものはすべて、サイトに組み込まれたコンテンツエディタの Sanity にあります。山行は 1 つのフォームで、一般的な情報から、ルートと行き帰りの段取りまで、タブに分かれています。グレードは、入力ではなく一覧から選ぶので、ページ上のラベルは常に尺度と一致し、ステージで代替案の入力欄が現れるのは、彼がそのステージを省略可能に設定してからです。

ホームページも同じ方法で編集でき、スライドショーの写真から、このプロジェクトについての文章までが対象です。彼が公開すると、サイトは変更を自動的に取り込むので、開発者の手は要りません。
