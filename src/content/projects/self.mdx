# Neofetch, for Windows

Self prints your system information in the terminal next to an image or a piece of ASCII art. On Linux that is what [Neofetch](https://github.com/dylanaraps/neofetch) does. I wanted the same thing in PowerShell, so I wrote it in Python.

## What it shows

One run prints the operating system, host, kernel, uptime, installed packages, shell, resolution, window manager, theme, terminal, font, CPU, GPU, memory and disk, and ends with the terminal's colour palette. The readings are cached between runs, so the second start is quicker; `self --no-cache` reads everything fresh.

## Pictures made of characters

A terminal cannot show pixels, so Self builds the image out of text. There are two ways to do it:

- **Block** uses the half-block character `▀`. Its top half takes the text colour and its bottom half the background colour, so one character cell carries two pixels in full colour.
- **Braille** uses the dot patterns of braille characters `⠿`. The dots are finer than blocks, but each cell has a single colour.

I recommend block: at this size colour matters more than resolution. If you would rather have no picture at all, Self prints ASCII art instead: the repository ships a few, from the Windows logo to Totoro, and a template for your own.

## Install and use

One line in PowerShell installs it for the current user. No administrator rights are needed.

<CodeBlock
  code={`iwr -Uri "https://raw.githubusercontent.com/lyfe691/self/main/install.ps1" -UseBasicParsing | iex`}
  fileName="install.ps1"
  lang="powershell"
/>

After that, `self` is a command like any other:

<CodeBlock
  code={`self                 # run with the default settings
  self --setup         # the setup wizard
  self --update        # update to the latest version
  self --image <file>  # use a specific image
  self --ascii <file>  # use ASCII art instead
  self --height <n>    # set the image height
  self --width <n>     # set the image width
  self --config <path> # use another config file
  self --no-cache      # skip the cached system info`}
  fileName="usage"
  lang="bash"
/>

## Themes

Colours and layout come from a config file. It ships with a default theme and a PowerShell one, and the colours are the terminal's own. `self --setup` walks through the choices, so nobody has to edit JSON by hand.
