# Montu，一份瑞士登山路线日志

[montu.ch](https://montu.ch) 收集了一位朋友在瑞士的登山路线，夏季和冬季的都有，每一条都用德语写成，配着他自己拍的照片。这个网站是我为他做的，他可以自己发布新路线，用的是浏览器里的内容编辑器。

## 他想要什么

他想要一个地方，按他记忆中的样子保存自己的路线。网站用它自己的话说出了这一点：技术细节只是“sanfte Wegweiser”（温和的路标），整个网站是“mehr Tagebuch als Führer”，也就是日记多于指南。所以每个页面都以一张照片和他的文字开头，数据跟在后面，供想去的人参考。

## 路线页

一条路线从上到下依次是：

1. 题图照片，附有路线类型、难度等级、地区、海拔范围和日期。
2. 他的介绍。
3. 关键数据、海拔剖面图和地图。
4. 各个分段，依次排列。
5. 指向沿途山屋、缆车和其他地点的链接，由他视情况添加。

## 一个 GPS 文件生成地图和海拔剖面图

GPS 手表或手机应用会把一次登山记录成一个 GPX 文件：线路是一串点，每个点都带着海拔。他把这一个文件上传到这条路线上。页面会在地形图上画出线路，起点是绿色图钉，终点是橙色图钉，并用同样的那些点绘制海拔剖面图。剖面图会自己选择比例尺，所以一次短途滑雪和一次长途穿越都能看得清楚，把指针移到剖面图上还会读出对应的高度。

难度等级遵循瑞士阿尔卑斯俱乐部的分级：

| 路线类型   | 分级                                           |
| ---------- | ---------------------------------------------- |
| 徒步       | 从 T1（轻松步行）到 T6（艰难的高山徒步）       |
| 滑雪与高山 | 从 L（容易）到 EX（极其困难）                  |
| 雪鞋徒步   | 从 WT1（轻松步行）到 WT6（要求很高的高山路线） |

在路线上悬停或点按难度等级，就会写出它的完整含义、指出所属的分级，并链接到对它的说明。

## 设计

标题用衬线体，正文用安静的无衬线体，照片铺得很大，带着圆角。菜单是角落里的一块小玻璃面板，会标出你所在的章节，里面有浅色、深色和跟随系统设置之间的切换。

## 他自己编辑的部分

网站用 Next.js 构建，访客读到的一切都存放在 Sanity 里，这是一个内置于网站的内容编辑器。一条路线就是一张表单，按标签页划分，从基本信息到线路和交通安排。难度等级是从列表里选的，而不是手动输入，所以页面上的标注总是和分级一致；一个分段只有在他把它标记为可跳过之后，才会要求填写替代方案。

首页也用同样的方式编辑，从幻灯片里的照片到介绍这个项目的文字。他发布之后，网站会自己更新，不需要开发者。
