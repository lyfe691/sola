# 一张配送车队的实时地图，专为办公室的电视而做

fleetmap 是瑞士一家配送公司放在办公室电视上的那块屏幕。每辆货车都在地图上，并随着行驶而移动，所以房间里的任何人都能看到每辆车在哪里、接下来去哪里，以及有没有晚点。这是我为这家公司做的。

控制台本身是内部使用的，所以本页的一切都来自一份跑着演示数据的副本：三辆货车在巴塞尔、伯尔尼和苏黎世之间跑着虚构的行程。

## 整个车队，一屏看全

地图上的每辆货车都指向它的行驶方向，并从一个上报的位置平滑地滑向下一个。它的颜色说明它的状态：

| 颜色   | 货车的状态                                 |
| ------ | ------------------------------------------ |
| 绿色   | 在行程中                                   |
| 琥珀色 | 等待下一个任务                             |
| 红色   | 照目前的进度，到下一个停靠点将晚五分钟以上 |
| 灰色   | 失联：手机已停止上报位置                   |

留出五分钟的余量，是为了不让一点点堵车就触发地图上的警示。

地图旁边的列表里，每辆货车都有一张卡片，显示到下一个停靠点的时间和剩余的停靠点数量。不需要任何人手动输入来保持更新：司机的手机会发送位置，每辆货车当天的停靠点则自动传入。

## 一次看一辆货车

点按一辆货车，地图就会飞到它所在的位置，并显示它当天的路线。停靠点按顺序编号，下一个停靠点会标出货车预计何时到达，已经行驶过的路段变成灰色，其他货车则淡出。地图上的一张卡片显示货车的速度、到下一个停靠点的预计到达时间，以及车上装了多少订单。

## 回放一天

在历史记录里选一辆货车和一天，它记录下的轨迹就会画在地图上。回放速度最高可达真实速度的 120 倍，地图会跟随货车，也可以把滑块拖到任意时刻。行驶距离、在路上的时间和 GPS 点数显示在地图下方。

## 为电视而建

控制台针对触摸屏排版，两侧的面板都可以收起，让地图铺满整个屏幕。它有浅色和深色两套主题，除非有人在设置里选定一套，否则跟随系统。货车一旦落后，它剩下的路线就会变红。

设置照顾到了看这块屏幕的人：

- **语言**：控制台默认使用瑞士德语，也可切换为英语，日期和时间在两种语言里都按当地的习惯书写。
- **对比度**：为房间另一头的屏幕准备的高对比度模式。
- **动效**：减弱动效的模式，货车不再平滑移动。
